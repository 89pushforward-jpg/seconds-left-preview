# SECONDS LEFT — prototype

Responsive static prototype for the US-facing SECONDS LEFT funnel.

- The free guide downloads directly from the page.
- The paid path is an explicit test-mode interaction. It collects no payment information, charges nothing, and does not include the paid PDF.
- Run locally with `python -m http.server 4173` and open `http://localhost:4173`.

The brand name, guides, copy, and illustrations are working materials supplied for this project.
